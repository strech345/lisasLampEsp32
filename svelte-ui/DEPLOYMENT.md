# Deployment Process

This project uses pre-built gzip files in the `data/` directory for deployment to the ESP32. These files are build artifacts that should be updated whenever the UI changes.

## Building for Deployment

1. Build the Svelte application:
   ```bash
   cd svelte-ui
   npm run build
   ```

2. Process files for ESP32 deployment:
   ```bash
   node build-esp32.js
   ```

3. This will update the gzip files in the `data/` directory:
   - `data/app.js.gzip` - The compiled JavaScript bundle
   - `data/index.html.gzip` - The HTML template
   - `data/pico.min.css.gzip` - The CSS framework (if present)

## Git Workflow

The gzip files in `data/` are intentionally committed to allow deployment without requiring a build environment. When the UI changes:

1. Run the build process as described above
2. Commit the updated gzip files along with your source changes
3. Deploy to the ESP32

## Cleaning Up Old Files

The build script automatically removes outdated files that are no longer generated by the current build process.
